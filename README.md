# price-tracker
## Overview

A lightweight price-tracking tool for AliExpress products. Enter a product URL and a target price through the dashboard, and the app scrapes the current price using Selenium, logs it to CSV, and sends an alert via email and Telegram if the price drops below your target.

Built as a freelance-ready demo covering Python automation, web scraping, and bot/notification integration.

**Stack:** Python, Selenium, Flask, Jinja2, SMTP, Telegram Bot API
